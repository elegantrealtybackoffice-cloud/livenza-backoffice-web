# Livenza Back Office Web 1.5.8

Web 1.5.8 is a secure workflow, large-media reliability and responsive-accessibility release.

## What changed

### Aadhaar agreement autofill

- The server tries text extraction for searchable PDFs, Tesseract OCR, RapidOCR and then the optional configured AI enhancement.
- OCR input is bounded to two rendered PDF pages or one resized image to protect small cloud workers.
- The browser shows deployment/reader diagnostics instead of the old generic “could not read” message.
- Aadhaar files are processed transiently and are not stored by the extraction route. Autofill does not verify identity with UIDAI.

### Agreement Studio

- Four steps: Party Details → Property Terms → Clauses → Preview & Sign.
- Visual cards for 11-Month Residential, Commercial and Leave & License, with all other presets retained.
- Local form auto-save indicator and draft restore for unsaved new agreements.
- Reusable landlord and tenant profiles with encrypted-at-rest JSON payloads.
- Livenza-owned geometric agreement banner, formal office identity, inline tooltips, protected-workspace disclosure, 48 px controls, fluid headings and darker WCAG-readable copy.

### Video Wall

- Signed TUS resumable upload reservation generated by the server; the service-role key is never sent to the browser.
- The browser uploads 6 MB pieces directly to the Supabase storage hostname and resumes from the confirmed upload offset after transient network failures.
- Livenza verifies the object, then creates the VideoAsset row so uploaded media appears in Available Media and screen selectors.
- The legacy multipart path remains for no-JavaScript uploads up to 50 MB.
- Rotation remains available only for registered TV players; the ordinary portal no longer offers manual display overrides.

### Query Sheet

- 30 blank rows are always visible and do not create database records until meaningful data is entered.
- Existing rows auto-save; blank and dirty rows can be committed together using Save All Changes.
- Excel-style tabular paste distributes copied cells across rows/columns.
- `.xlsx` and `.csv` import recognises common lead headers and saves up to 1,000 data rows per file.

### Authentication, mobile and mascot

- Device passkey / Windows Hello is the primary login action; password and gesture pattern are compact fallbacks.
- Gesture pattern accepts a continuous pointer or touch path with a visible connection line.
- Header and workspace use native responsive CSS; costly mobile effects remain suppressed by performance mode.
- Mascot outer wrapper uses `pointer-events:none`; only the trigger and open panel accept interaction.
- Main content reserves at least 80 px at the bottom. The mascot collapses after scroll and becomes a 44 px bubble below 400 px.

## Deployment checklist

1. Deploy as Docker from `render.yaml` so `tesseract-ocr` is installed.
2. Run `migrations/web_v1_5_8.sql` if automatic table creation is restricted.
3. Set a stable `INTEGRATION_ENCRYPTION_KEY`.
4. Configure Supabase storage credentials and size limits. `VIDEO_WALL_MAX_MB` defaults to 2048 MB but does not override a lower Supabase bucket/global limit.
5. Configure `WEBAUTHN_RP_ID` and `WEBAUTHN_ORIGIN` for production passkeys.
6. Verify `/version`, Aadhaar OCR, MP4 upload, party-profile save/apply, query batch save and mobile login.
