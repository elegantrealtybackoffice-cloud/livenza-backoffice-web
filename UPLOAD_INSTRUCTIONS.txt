LIVENZA WEB 1.5.12 — DIRECT ROOT UPLOAD

1. Extract this ZIP.
2. Upload its contents directly to the root of the existing repository, preserving templates/, static/, migrations/ and windows-kiosk/.
3. Run migrations/web_v1_5_12.sql in Supabase SQL Editor. Also run the older web_v1_5_0.sql and web_v1_5_8.sql migrations if they were not previously applied.
4. Keep OPENAI_API_KEY configured to enable AI-styled personal avatars. Optional: set OPENAI_AVATAR_MODEL and OPENAI_AVATAR_QUALITY.
5. Keep the Google, WhatsApp, integration-encryption and WebAuthn environment values listed in README.md.
6. Deploy with the supplied Dockerfile/render.yaml and confirm /version returns Web 1.5.12.

Web 1.5.12 makes the profile photo the user's live mascot and fixes rotation hanging by moving the display menu outside the transformed workspace and reducing expensive effects only during rotation.

The Windows scripts are setup helpers. Full operating-system restriction requires Microsoft Assigned Access as described in windows-kiosk/README_WINDOWS_KIOSK.md.
