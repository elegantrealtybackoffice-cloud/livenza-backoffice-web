   - Tesla OS 27
   - Version 27.0.1
   - Build 27A101
   - Hotfix 10 Light Shell
   - revision `27A101-H10L-20260827D`
2. Inspect the main document response headers. It MUST include:
   - `X-Livenza-Build: 27A101`
   - `X-Livenza-Hotfix: Hotfix 10 Light Shell`
   - `X-Livenza-Revision: 27A101-H10L-20260827D`
3. In browser DevTools → Network, reload Home and verify the new requests include:
   - `home_light.css?rev=27A101-H10L-20260827D`
   - `home_light.js?rev=27A101-H10L-20260827D`

CACHE NOTE
Hotfix 10 intentionally uses a unique asset revision because static files are served with a long immutable cache lifetime. The OS version remains 27.0.1, but the asset query revision changes so browsers/CDNs cannot reuse Hotfix 9/older Hotfix 10 CSS/JS. The default wallpaper also has a revision-specific filename for the same reason.
