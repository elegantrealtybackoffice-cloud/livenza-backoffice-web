CACHE NOTE
Hotfix 10 intentionally uses a unique asset revision because static files are served with a long immutable cache lifetime. The OS version remains 27.0.1, but the asset query revision changes so browsers/CDNs cannot reuse Hotfix 9/older Hotfix 10 CSS/JS. The default wallpaper also has a revision-specific filename for the same reason.
