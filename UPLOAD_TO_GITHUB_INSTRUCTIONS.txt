LIVENZA WEB 1.7.1 — GITHUB BROWSER UPDATE

This ZIP contains only production files changed/new from Web 1.7.0 to Web 1.7.1.
It is designed to stay below GitHub's 100-file browser upload limit.

IMPORTANT
1. Extract this ZIP on your computer.
2. In GitHub, upload each root-level file to the repository root and replace existing files when asked.
3. For files under templates/, static/, and migrations/, open the matching folder in GitHub before uploading those files so the paths remain identical.
4. Do NOT upload the ZIP itself as the application update. Upload its extracted contents.
5. In Render/production Environment, set and keep LIVENZA_VAULT_MASTER_KEY stable. Never commit this secret to GitHub.
6. If your managed database does not allow automatic table creation, apply migrations/web_v1_7_1.sql.
7. Commit the GitHub changes and let Render redeploy.
8. After deployment, open /version and confirm Web 1.7.1.

KEY UI CHECKS
- Applications opens as a translucent left-side drawer instead of the old large white mega-menu.
- Agreement Studio exposes Landlord Master and Tenant Master.
- Sensitive master values are masked. Admin re-authentication is required for reveal/protected document download.
- Applying a master fills empty agreement fields by default; Replace Existing Values is explicit.
