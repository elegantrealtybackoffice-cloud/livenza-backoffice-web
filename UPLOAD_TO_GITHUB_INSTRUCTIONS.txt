LIVENZA WEB v1.8.0 — GITHUB BROWSER UPDATE

Base required: Web 1.7.1
Target: Web 1.8.0

This package contains only production files changed/new from v1.7.1 to v1.8.0.
It is below GitHub's 100-file browser-upload limit.

UPLOAD
1. Extract this ZIP on your computer.
2. Open your existing Livenza GitHub repository.
3. Upload the extracted production files to the matching repository paths. Root files go to the repository root; files under data/, migrations/, static/, and templates/ go into those existing folders.
4. Replace/overwrite older files when GitHub asks.
5. Commit with a message such as: Upgrade Livenza Web to 1.8.0
6. Let Render redeploy.
7. Open /version and confirm Web 1.8.0.

IMPORTANT
- Do not upload this ZIP itself as the application. Upload its extracted contents.
- Keep LIVENZA_VAULT_MASTER_KEY stable in Render.
- Apply migrations/web_v1_8_0.sql if your production database does not permit automatic schema creation.
- The full WebGL host is local code; no CDN dependency is required for the live 3D host.
