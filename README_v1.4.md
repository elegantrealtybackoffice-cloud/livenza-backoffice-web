# Livenza Back Office Web 1.4 — Video Wall Studio

Seventh suite added: Video Wall Studio.

Key capabilities:
- Register unlimited TV/screen endpoints with unique player URLs.
- City, property/location and device labels per screen.
- Each screen can run its own video/image playlist.
- Playlist looping, image slide duration, muted autoplay and fit modes.
- Rotation from 0–359 degrees for horizontal, vertical, inverted or angled mounting.
- ONLINE/OFFLINE heartbeat status.
- One-click Festive Takeover to run one commercial across all enabled screens.
- Stop Takeover returns every screen to its own playlist.
- Persistent media library in Supabase Storage, plus external/CDN URL support.

Direct file uploads need the Render secret `SUPABASE_SERVICE_ROLE_KEY`. External/CDN URLs work without it.
