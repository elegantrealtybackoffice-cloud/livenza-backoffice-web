# Livenza Back Office Web 1.5.2

This release refines the visual experience without changing the existing security, cloud-integration or operational workflows.

## Header

- The top-header Livenza mark is a transparent PNG with no square or white tile.
- The logo does not rotate. Its conic light, halo and orbit dots remain independent animated layers behind the mark.
- At the top of a page, the header is transparent. After scrolling, it transitions into a translucent glass ribbon with a live progress light.

## Visual workspace

- The dashboard includes a responsive hospitality gallery and photo-backed application tiles.
- Agreements, rooms, tenants, food, video wall, billing, queries, reviews, WhatsApp, Email, Drive, Admin and Settings receive compact contextual image ribbons.
- Motion includes staggered reveals, restrained depth on pointer movement, image zoom, count-up metrics and subtle title lighting.
- Keyboard focus states, mobile layouts and reduced-motion handling are included.

## Deployment

No new database migration is required for Web 1.5.2. Deploy the files normally and verify that `/version` reports `Web 1.5.2`.
